Repeat templates

Render nested arrays

Load an object with an array, then set items to its property path and as to the item alias. Nest a second loop for each item’s children. Outer aliases stay available inside nested loops; a reused alias shadows its outer value.

Open Nested loops and an included row

Share row markup

Inside a row template, use cf-include for shared markup. Included markup and assigned slot content inherit the row context. Keep paths relative to the entry page.

Provide a static template data-state="empty" for an empty array. A missing or non-array value is an error, not an empty result. See cf-loop and Bindings.

Use cf-if to choose a branch once in the current data or loop context. Only the selected template is rendered; nested data keeps its own scope. Loading, error, and loop empty templates remain static.
