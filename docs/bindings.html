Bindings

Inside a data template, bind own-property paths through cf-text, cf-href, cf-src, cf-alt, cf-id, cf-title, cf-aria-* and cf-data-*. Text is escaped through textContent. Missing values become empty strings. Unsafe path segments and unsupported bindings fail rendering. Links permit HTTP(S), mailto and tel; image sources require HTTP(S). This is not an expression evaluator or sanitizer.
