Bindings

Write text or a supported attribute from a property path during data rendering. Bindings are not processed in ordinary page markup or standalone includes.

Property paths and conversion

Each segment must match [A-Za-z_$][\w$]*. Use dotted own-property paths, such as project.author.name. Prototype traversal and segments __proto__, constructor, and prototype are rejected. Expressions, array indexes, bracket access, and interpolation are unsupported.

Values convert with String(value ?? ""). Null, undefined, and missing properties become an empty string; false becomes "false", zero becomes "0", arrays and objects use JavaScript string conversion. Invalid paths and unsupported cf-* attributes on ordinary rendered elements fail the data render. Each successfully applied binding attribute is removed.

cf-text

Sets textContent, replacing all existing children. Empty values clear the text. Markup is treated as text, never parsed as HTML.

cf-href

Sets href for a non-empty URL whose resolved protocol is HTTP, HTTPS, mailto, or tel. Relative URLs and fragment links are allowed and resolved against the page base. Empty or disallowed schemes remove an existing href. A malformed URL that throws during parsing fails rendering; it is not silently removed.

cf-src

Sets src for a non-empty HTTP or HTTPS URL. Relative URLs resolve against the page base. Empty values and other schemes (including data, blob, and javascript) remove an existing src. Malformed URLs fail rendering. Use this on images; CFJS does not check file availability or handle image load failures.

cf-alt

Sets an image’s alt to the converted string. Empty values preserve alt="" for decorative images.

cf-id

Sets id to the converted string. An empty string removes an existing id. CFJS does not ensure uniqueness.

cf-title

Sets title to the converted string; an empty string removes the attribute.

cf-aria-*

A binding such as cf-aria-label="project.label" writes aria-label. The suffix accepts word characters and hyphens. Empty values remove the target attribute; false writes the string "false", rather than removing it.

cf-data-*

A binding such as cf-data-kind="project.kind" writes data-kind. The suffix accepts word characters and hyphens. Empty values remove the target attribute; false and zero remain string values.

Scope and timing

Bindings run once on ordinary elements in the result template, before mounting. Templates and nested data elements are skipped. Loops add an item alias; includes and their assigned slot content inherit that context. Loading, error, and empty fallbacks do not receive bindings. See Render JSON and global data.

Use cf-if to choose a branch once in the current data or loop context. Only the selected template is rendered; nested data keeps its own scope. Loading, error, and loop empty templates remain static.
