Compose reusable fragments

Create a reusable fragment

Put the shared article structure in card.html. Add a named slot for the heading and a default slot for body content. Fallback inside each slot is used when no matching child is supplied.

Supply content from a page

Set slot="heading" on a direct child of cf-include. Unnamed elements and text nodes fill the default slot. Only the first matching slot receives a given child; unmatched children are discarded. Whitespace text can fill a default slot.

Composition is one-time. Assigned nodes are cloned, so attach listeners after mounting rather than expecting listeners on supplied nodes to transfer. See Slots for the full rules.

Initialize the result

Put instance initialization in a function wrapper inside the fragment, or delegate events from the page. Inline classic scripts run after the whole include tree is inserted. Keep critical content outside slow include trees. Relative script, image, and nested include URLs still belong to the entry page. See Scripts and styles and Paths and requests.
