Scripts and styles

Trusted fragment scripts activate once per mounted instance after the full DOM is present. Inline classics execute in order. Non-async external classics keep insertion order but inline scripts do not wait for them. Modules and async scripts retain native browser behavior; defer has no parser-time meaning. Load events do not wait for external scripts or modules. Nonces are preserved. Identical trimmed inline styles are deduplicated in the document head, before the first stylesheet link. Nested template scripts stay inert.
