Quickstart

Load the runtime

Download cfjs.js beside your page. Load it with <script defer src="./cfjs.js"></script> and explicitly close custom-element tags. Serve the directory over HTTP(S), rather than opening a file URL.

The hosted examples keep the runtime in the docs vendor directory and use ../vendor/cfjs.js. Change that script path to ./cfjs.js when placing the runtime beside your page. The example stylesheet only formats the preview.

Create a fragment

Create card.html and include it from index.html. The live example shows the same files served with this documentation. Each path is relative to the entry document, including paths inside fragments.

The include wrapper disappears after the fragment is ready. Before that, its children provide visible fallback content. On failure, those original nodes remain. See the include reference.

Add data

For a dynamic title, define a property on window before the runtime runs. A data template reads it through the alias in name. Continue with Render JSON and global data.

CFJS composition and data rendering run entirely in the browser. Serve the authored HTML and runtime directly over HTTP(S); JavaScript is required.
