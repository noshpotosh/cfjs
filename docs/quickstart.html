Quickstart

Load the runtime

Download cfjs.js beside your page. Load it with <script defer src="./cfjs.js"></script> and explicitly close custom-element tags. Serve the directory over HTTP(S), rather than opening a file URL.

The hosted examples keep the runtime in the docs vendor directory and use ../vendor/cfjs.js. Change that script path to ./cfjs.js when placing the runtime beside your page. The example stylesheet only formats the preview.

Create a fragment

Create card.html and include it from index.html. The live example shows the same files served with this documentation. Each path is relative to the entry document, including paths inside fragments.

The include wrapper disappears after the fragment is ready. Before that, its children provide visible fallback content. On failure, those original nodes remain. See the include reference.

Edit and run examples

Choose Edit example to load the local syntax-aware editor. File tabs keep separate text, selections, and undo history. Edit any listed HTML, JavaScript, or JSON file, then choose Run or press Ctrl/Cmd+Enter to refresh the complete preview. Typing never executes code; unrun edits are marked. Copy uses the current file contents.

Reset example restores every published file and the original result. Exit editor returns to source view with your drafts retained. Each example is independent. Drafts last only until navigation or reload and are never saved or shared. Press Escape inside the editor to focus Run, or Tab to leave it. Open original example always opens the published standalone file.

Edited snapshots run in isolated iframes without access to the docs document or storage. The canonical runtime and shared stylesheet are fixed. Only listed files are available: external dependencies, missing local resources, module imports, creating files, and renaming are outside this version. Runtime, JSON, include, and resource errors appear as text below the preview; correct the file and Run again. Error names are included when available. Wording varies by browser; isolated previews may report only Script error. for some script failures. The loading and error states example deliberately includes a failing provider. If the editor cannot load, the original source and preview remain usable.

Add data

For a dynamic title, define a property on window before the runtime runs. A data template reads it through the alias in name. Continue with Render JSON and global data.

CFJS composition and data rendering run entirely in the browser. Serve the authored HTML and runtime directly over HTTP(S); JavaScript is required.
