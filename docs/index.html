Introduction

CFJS composes HTML fragments, loads JSON or global JavaScript data, and repeats templates in the regular DOM. Add one browser script to an HTTP(S) site; no application build step or runtime dependencies are required.

Preparing v0.1.0. CFJS is an early, pre-1.0 framework developed alongside a portfolio that uses it. The API is still evolving; expect changes before 1.0.

Choose a feature

Use cf-include for shared markup and slots for page-specific children. Use cf-data to load a value, cf-loop to repeat an array, and bindings to write text and attributes.

Start with the Quickstart, or follow a guide to compose reusable fragments, render data, or repeat templates.

Rendering model

CFJS uses one-time composition in the light DOM. Existing CSS selectors and browser tools apply. Includes create fresh nodes; data elements render once. Changing a source attribute or mutating a value does not update an existing result.

Use trusted fragments and code. CFJS is not a sanitizer, a reactive framework, or an expression evaluator. Read limitations and troubleshooting before integrating untrusted content.

CFJS composition and data rendering run entirely in the browser. Serve the authored HTML and runtime directly over HTTP(S); JavaScript is required.
