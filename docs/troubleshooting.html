Troubleshooting and limitations

Symptoms, causes, and remedies

Fallback never disappears
Inspect data-cf-error, the console, and Network panel. Serve over HTTP(S); check the response status, CORS, CSP, and document-relative src path. HTML includes have no timeout.
Unknown data source
Define the own property on window before the element starts. Expose module and const/let bindings explicitly. Do not depend on an external script or module finishing first.
Content remains blank
Check the alias and each own-property path. Missing values become blank text. An empty loop without an empty template emits nothing.
Loop fails instead of showing empty
items must resolve to an array. Supply [] for an empty result; null or a missing property is an error.
Template renders literal binding attributes
Put bindings and loops inside a cf-data result template. Loading, error, and empty templates are static. Nested cf-data elements cannot read an outer alias.
Link disappears
cf-href removes empty and disallowed protocol values. Use an HTTP(S), mailto, tel, relative, or fragment URL.
Changing src has no effect
Rendering is one-time. Create a new element from the original template to retry. Successful responses remain cached for the document lifetime.
Fragment styles or scripts affect other instances
The DOM and styles are global. Wrap initialization in a function and clean up your own timers and global listeners.
Nested include or asset returns 404
Resolve the path against the entry document, not the fragment’s directory. Test direct page URLs under the intended deployment subdirectory.
Default slot fallback disappears
Whitespace text nodes are valid default-slot assignments. Remove unintended supplied whitespace or supply explicit body content.

Supported boundaries

Trusted HTML and code only; includes are not a sanitizer. There is no reactivity, interpolation, arbitrary expression evaluation, event binding directive, source registration API, reload API, cancellation API, or automatic lifecycle cleanup. Browser HTML parser placement rules still apply, especially inside tables and selects; author ordinary fragments rather than complete documents or destination-dependent bare table rows.

Modern browser APIs including custom elements, templates, fetch, Object.hasOwn, and AbortSignal.timeout are required. The browser suite verifies the selected engine; it is not a promise of support for all historical versions. See request constraints and script readiness.

Use cf-if to choose a branch once in the current data or loop context. Only the selected template is rendered; nested data keeps its own scope. Loading, error, and loop empty templates remain static.
